## Scope, standards and ownership

Primary visual ownership: K-Tour ID preparation and all method routes; direct and contextual Account/Person/Age/Payment/credential gates; Pass readiness and capability explanations; wallet, all funding methods, checkout/benefit/payment/receipt/refund; reservation; general Labs signer/bridge/traits/badge. Focused keepsake consent and Person-gate integrity belong here, while Designer 2 owns its consumer presentation and exact-origin journey composition.

The coordinator owns runtime inspection of Partner verification/settlement/support/audit events and optional guide-save execution. They remain explicitly inventoried below to prevent an unowned feature. Designer 1 owns public guide reading and place service entry; Designer 2 owns saved-guide cards, reservation history in Tables, My Korea purchase cards, Pass composition and stamps. Shared contextual handoffs require both origin and task review; they are not extra public URLs.

Read: `docs/toss-grade-ux/00_UX_STANDARD.md`, `00_PRD_PRESERVATION_LEDGER.md`, `docs/ux-refinement/2026-09-15/visual-standard.md`, `sitemap-code.md`, `sitemap-browser.md`; the flow contracts, state and preservation sections of FL-004 through FL-010 and FL-016 through FL-018; relevant current B components and models. Old **ONDO consumer branding is superseded by K-Tour ID**. Legacy A entry components and archived routes are not current consumer screens. The 2026-09-16 visit/Pass/keepsake amendment supersedes older mandatory My Korea/Labs detours.

Mode notation:

- **N**: normal public UI with explicit `?review=0`.
- **R**: public review/sample UI, either explicit `?review=1` or visible sample-entry action. The local environment can default to sample, so absence of a query parameter is not proof of N.
- **C**: conditional on a preceding public operation, current gate or existing object.
- **Q**: authoring/injected QA only; not a public entry or a substitute for a permitted positive identity/payment path.
- **S**: source-defined branch whose browser reachability is not yet established. A failure occurring naturally can be N/R even if deterministic triggering requires a diagnostic condition.

`sample-environment.ts` defaults to sample unless `NEXT_PUBLIC_ONDO_EXECUTION_MODE=provider`. `use-qa-controls.ts` separates public review opt-in from injected runtime cases, which additionally require `NEXT_PUBLIC_ONDO_QA_CONTROLS=1`. Storage/credential/financial-authority injection was not used to claim public reachability. The inventory initially marked every row unverified; the Stage2 ledger below records exactly which states were subsequently observed and which remain gaps.
