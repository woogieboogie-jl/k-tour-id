## Harvey가 연결할 때 지킬 계약

이번 작업은 **새 필수 백엔드/API 범위를 추가하지 않는다**. 해커톤 최소 흐름은 여전히 무료 가이드 읽기 → 선택 저장 → CX → OpenDID → 사용자 승인·Sui 실행 → 최종 자격/DB 저장 → 독립 OmniOne 기록이다. [짧은 인계](./HARVEY_HACKATHON_HANDOFF_2026-09-14.md)와 [가이드 v2 연결 계약](./EXPERIENCE_MOCK_HANDOFF_2026-09-15.md)을 따른다.

1. **정확한 행동 복귀:** prerequisite 완료/취소 후 원래 장소·주문·Table·스크롤·포커스를 복원한다. 화면을 여는 것은 권한을 부여하거나 이전 동의를 재사용하는 일이 아니다.
2. **권한·금전 분리:** Person/Age/Payment/VC를 합치지 않는다. 스테이블코인 출발 완료, KRW 표시 잔액 반영, 결제 완료, 환불 완료는 독립 결과다. 이번 최소 해커톤에서는 금융·예약·bridge 실연동을 계속 제외한다.
3. **Table·프로필:** 목록/상세/저장 계획은 같은 Table 일정의 동일한 원천을 쓴다. 직접 입력한 프로필은 신원 확인에서 자동 채우지 않는다. 항목별 공개 동의와 작성 중 이탈 확인을 유지한다.
4. **방문·기념품:** Pass가 Journey 표시를 소유한다. 장소당1스탬프, 결제/가이드 저장은 자동 적립 없음. 현재 방문 기록은 페이지 메모리 샘플이고 reload로 초기화한다. 10곳 기념품은 별도 signer 준비·명시 동의·Person·1회 실행 뒤 원 컬렉션으로 돌아온다. 실제 검증 방문/영구 기록/온체인 NFT를 구현한 것으로 간주하지 않는다.
5. **자격 공유 안내:** 실제 requester, 고정된 purpose, 필요한 yes/no 또는 확인 불가, retention, 실제 expiresAt을 승인 전에 표시한다. 이 목업은 외부 전송 없이 현재 페이지 메모리에 보관하며 창 닫기로 삭제되지 않는다. reload/샘플 초기화 시 지워지고 2분 요청 만료는 데이터 삭제 기한이 아니다. 실연동 시 실제 서버 보관 정책을 안내에 연결해야 하며 이 샘플 설명을 운영 정책으로 복사하지 않는다.

공개 가이드 컬렉션의 브라우저 저장, 메모리 방문 스탬프, 선택형 기념품, 실제 OpenDID VC는 서로 다른 데이터다. UI 정리가 이들 사이에 새로운 자격이나 금융 권리를 만들지 않는다.
