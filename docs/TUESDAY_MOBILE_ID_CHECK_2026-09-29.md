# 화요일 팀원과 함께 확인할 것 — 모바일 신분증

목표는 **K-Tour에서 시작한 요청을 실제 신분증 앱에서 승인하고, 같은 요청의 서버 결과까지 확인하는 것**입니다. QR이 뜨거나 앱이 열리는 것만으로 성공으로 세지 않습니다. 팀원은 자신의 휴대폰에서만 동의하고, 신분증·QR·개인정보를 전달하지 않습니다.

## 먼저 준비할 것

- 팀원: 모바일 운전면허증을 사용할 수 있는 휴대폰. 현재 CX 요청은 `comdl` / `AdultVerify`라 PASS나 다른 신분증을 대신 쓸 수 있다고 보장하지 않습니다.
- 담당자: Harvey에게 **일반 모바일 신분증 앱인지, 별도 테스트베드 앱인지** 먼저 확인합니다. 테스트베드라면 공식 설치 경로와 해당 자격증명 조건을 받습니다. 임의 APK나 신분증 재발급을 먼저 진행하지 않습니다.
- 검수 담당자: 아래 [환경 인계 문서](./HARVEY_ENV_HANDOFF_2026-09-26.md)의 CX 보호 Preview가 유효한지 확인하고, 팀원에게 **확인한 링크 하나와 필요한 접속 코드**를 안전하게 전달합니다. 코드를 팀원이 Vercel에서 직접 찾게 하지 않습니다.
- 공개 `ktour-id.vercel.app`은 지도 UI 배포입니다. 이번 실인증 검수는 공개 지도가 아니라 별도 보호 Preview에서 진행합니다. 오래된 Preview 링크를 확인 없이 재사용하지 않습니다.

접근 환경의 현재 만료 예정은 9월 30일 23:59:59 KST입니다. 개별 QR·인증 요청은 훨씬 먼저 만료될 수 있으므로 현장에서 새로 만듭니다. 화요일 날짜는 2026년 9월 29일입니다.

## 권장: PC 화면 + 팀원 휴대폰

1. PC에서 전달받은 **보호 Preview**를 열고, 지정된 장소 상세에서 **체험 혜택 보기 / See experience perk**를 누릅니다.
2. 필요한 경우 전달받은 접속 코드를 입력하고 안내에 동의합니다. 이 동의는 아직 신분증 인증 성공이 아닙니다.
3. **QR로 확인 → 모바일 신분증 확인 시작**을 눌러 새 QR을 표시합니다.
4. 팀원 휴대폰에서 올바른 **모바일 신분증 앱 → QR 촬영**을 선택해 PC의 QR을 촬영합니다. `나의 QR`을 보여주는 메뉴나 별도의 사업자용 검증앱이 아닙니다.
5. 앱에 표시된 서비스와 요청 정보를 확인합니다. 이상하면 중단합니다. 적절하다면 팀원이 직접 동의·정보 보내기와 앱의 본인 인증을 마칩니다.
6. PC의 K-Tour로 돌아와 **결과 확인 / Check result**을 누릅니다. 승인 전에 연속으로 누를 필요는 없습니다.
7. 화면의 결과와 원래 장소로 돌아가는 동선을 확인합니다. 검수 담당자는 아래 서버 조건까지 확인한 뒤 완료로 기록합니다.

휴대폰 한 대라면 3번에서 **앱으로 확인**을 선택합니다. 앱에서 승인을 마친 후 **원래 브라우저의 원래 탭**으로 돌아와 결과를 확인합니다. 앱 링크 생성과 실제 iOS/Android 왕복은 다른 검증 항목이므로 각각 기록합니다.

## 통과 기준 — 화면과 서버를 함께 확인

| 확인 | 통과 조건 | 담당 |
| --- | --- | --- |
| 앱 연결 | 올바른 앱과 서비스의 요청이 열림 | 팀원 |
| 본인 승인 | 팀원이 자기 기기에서 정보 제출을 승인함 | 팀원 |
| 결과 일치 | 생성한 요청과 조회한 요청이 같고, 공급자의 최종 결과가 확인됨 | 검수 담당자 |
| 동일인·성인 | 안정적인 CI 기반 동일인 결합과 성인 결과 확인. CI가 없는데 요청 ID로 대체하지 않음 | 검수 담당자 |
| 복귀 | 기존 장소와 선택 맥락으로 복귀. 승인 클릭이나 앱 열기만으로 혜택이 사용되지 않음 | 함께 |
| 재조회 | 같은 완료 요청을 다시 조회해도 중복 발급·사용·기록이 생기지 않음 | 검수 담당자 |

**범위:** 이 표가 통과해도 Sui 위임/실행, OmniOne 기록, Sumsub 여권 검증, OpenDID 발급까지 자동으로 완료된 것은 아닙니다. 현재 CX-only 보호 환경은 체인 실행을 의도적으로 차단합니다.

## 실패 상황도 두 가지 확인

- **미승인/취소:** 새 요청을 만든 뒤 앱에서 승인하지 않거나 취소합니다. K-Tour가 성공으로 바뀌지 않아야 합니다. 취소 후 새 요청으로 다시 시작할 수 있어야 합니다.
- **만료/복귀:** 요청이 만료됐거나 탭을 새로고침한 뒤, 남의 요청이나 예전 승인으로 통과하지 않아야 합니다. 실제 제공자 만료는 시간을 기다려 확인하고, 로컬 fixture 만료 검수와 구별해서 기록합니다.

실패하면 같은 QR을 계속 재사용하지 말고 **시각·오류 코드만 기록**한 뒤 중단합니다. 승인 성공 증빙을 위해 여러 번 불필요하게 개인정보를 제출하지 않습니다.

## 끝나고 전달할 결과

아래 양식이면 충분합니다. 접속 코드, QR, CI, JWT, 휴대폰 번호, 신분증 사진은 넣지 않습니다.

```text
검수 시각(KST):
휴대폰 OS / 브라우저:
모바일 신분증 앱 종류(일반/테스트베드):
경로(PC QR / 같은 휴대폰 앱 연결):
앱 승인: 성공 / 취소 / 실패
K-Tour 결과: 성공 / 미승인 / 만료 / 오류
오류 코드(있으면):
원래 장소 복귀: 정상 / 문제
서버 요청·동일인·성인 검증: 담당자 확인 완료 / 확인 필요
```

공식 사용 흐름: [모바일 신분증 개발지원센터의 QR 촬영·정보 보내기 안내](https://dev.mobileid.go.kr/mip/dfs/useguide/unmannedguide.do). 앱 버전에 따라 메뉴 배치는 달라질 수 있습니다. 상세 환경 조건은 [Harvey 인계 안내](./HARVEY_ENV_HANDOFF_2026-09-26.md)를 함께 봅니다.
