## 변경 범위

- 서울 3개를 보존하고 부산 3개(시장·커피·한 끼), 제주 3개(드라마·K-pop·지역 음식)로 맞췄다.
- 기존 캐러셀·지도·본문·상세·목록·뒤로 가기를 재사용한다. 별도 실험 UI를 공개 화면에 씌우지 않는다.
- 각 이야기는 한국어·영어·일본어와 출처를 가진다. 새 추천을 실시간 인기·영업·결제 가능 장소로 승격하지 않는다.
- 장소별 상세는 해당 이야기의 메모를 사용한다. 부산 시장에 서울 참기름 설명이 보이거나 제주 명소에 '시장' 제목이 붙는 하드코딩을 제거했다.
- 검증 가능한 실사 사진이 없는 새 장소에는 기존 일러스트를 명시해서 사용했다. 특정 업소 사진처럼 표현하지 않는다.

## 로컬 지도 이동이 달라 보인 이유

Sumsub 검수 창 실행기가 Playwright `reducedMotion: "reduce"`를 강제했다. 접근성 설정에 따라 지도 진입·스토리 이동 시간이 줄어드는 정상 동작이지만, 일반 UX 검수 기본값으로는 적절하지 않았다. 실행기는 일반 검수에서 `no-preference`, 명시적인 `--reduced-motion` 또는 `--smoke`에서만 `reduce`를 사용하도록 수정했다.

도시가 포함된 URL 직접 진입은 복원 동작이며 전국 지도에서 도시를 누르는 진입 애니메이션과 다르다. 실행 중인 이전 production 빌드는 소스 편집만으로 갱신되지 않으므로 최신 빌드/서버 재시작도 별도로 확인한다.

## 배포 경계

현재 통합 개발 브랜치의 `vercel.json`은 CX-only 보호 서버 빌드다. 공개 사이트의 `origin/main`은 `build:vercel:ondo-b` / `.ondo-b-standalone/.next`를 사용한다. **통합 브랜치 전체를 main에 fast-forward하지 않는다.**

공개 릴리스는 origin/main 기반 별도 워크트리에서 지역 콘텐츠·공유 상세 컴포넌트·공개 파일 허용목록·관련 검사만 반영한다. CX/Sumsub API, 체인 실행 경로, 환경 비밀값, Vercel 계정 설정은 공개 프론트 릴리스에 포함하지 않는다. 공개 UI 배포 성공을 실인증·체인 연동 완료로 보고하지 않는다.

- 세 도시 각 3개, 총 9개 이야기에 대해 장소 참조·도시 격리·3언어·좌표·로컬 이미지·출처 계약을 검증한다.
- 모바일 및 데스크톱에서 캐러셀 이동, 본문 읽기, 장소 열기, 목록 전환, 원래 지도 복귀를 확인한다.
