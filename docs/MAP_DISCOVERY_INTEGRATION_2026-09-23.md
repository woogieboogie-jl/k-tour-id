# 기존 지도 안의 이야기·Hot/Cool 목업

작업 브랜치: `preview/map-discovery-20260923` (로컬 전용). Harvey 최종 통합본과 기존 UX 위의 프런트엔드 변경이다. 새 배포, 원격 push, 체인 거래는 포함하지 않는다.

## 사용자 흐름

- **서울 지도 → ‘참기름 따라, 시장으로’ → 중부시장 핀·카드 → 시장 정보 → 같은 지도.** 특정 참기름 가게의 위치를 추정하지 않고 공식 시장 좌표를 사용한다. 원문과 장소 출처는 구분한다.
- **제주 지도 → ‘드라마 속 제주로’ → 촬영지 2곳 → 기존 장소 상세 → 같은 지도.** 기존 제주 상세·저장 동작을 그대로 사용한다.
- **기존 검색창 → Hot / Cool → 서울 장소 3곳 → 기존 음식점 상세 → 같은 추천.** `hot`/`cool`을 입력하고 Enter로도 진입한다. `hotdog` 같은 일반 검색은 바꾸지 않는다.
- 기존 도시 가이드의 해당 이야기에서도 같은 지도 결과로 연결한다. 독립 앱·별도 가입·새 저장함을 만들지 않는다.

Hot/Cool은 고정된 편집 추천 목업이다. 실시간 온도·혼잡도·현장 인기 순위를 주장하지 않는다. ‘추천 안내’에서 이를 확인할 수 있다. 그림은 일러스트로 표시하고, 보유한 실제 사진은 기존 권리·출처 정보를 유지한다.

## 기존 기능과의 경계

- 현재 도시와 분류, After 19 제한을 함께 적용한다. 조건 때문에 0~2곳이면 그대로 보여주며 다른 도시 장소로 3개를 채우지 않는다.
- 결제 가능 매장으로 등록되지 않은 추천 장소를 결제/혜택 대상으로 승격하지 않는다. 지갑의 결제 가능 매장 보기는 기존 경로를 유지한다.
- 리서치 음식점은 기존에 저장을 지원하지 않아 새 저장·인증 단계를 추가하지 않는다. 제주 장소는 기존 기능을 유지한다.
- 앱의 단일 MapLibre 지도와 기존 장소 상세를 재사용한다. 브라우저 뒤로/앞으로, 새로고침, 카드↔핀 선택, 지도/목록 전환에 추천 상태를 포함한다.
- API·DID·Sui·OmniOne 계약, 서버 데이터, 결제·예약 로직은 변경하지 않는다. 새 추천을 눌러 외부 인증이나 체인 실행이 시작되지 않는다.

## 실행·검수

앱 폴더에서 `node scripts/hackathon-local.mjs dev 3142` → `http://127.0.0.1:3142/`.

격리 실행기는 공급자 자격 증명을 상속하지 않으며 실체인 동작을 막는다. 이것은 **UX 목업 검수 환경**이지 실연동 완료 증거가 아니다.
