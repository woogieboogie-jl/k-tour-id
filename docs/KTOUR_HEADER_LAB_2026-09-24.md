- 확인: `http://127.0.0.1:3140/labs/header-preview`
- 실제 앱: `http://127.0.0.1:3140/?city=seoul`
- **9/25 후속:** 승인된 A 헤더를 실제 앱에 로컬 통합했다. 최신 구현·검수 범위는 [A 헤더 통합 기록](./KTOUR_HEADER_INTEGRATION_2026-09-25.md)을 따른다. 원격 푸시·배포는 하지 않았다.
- 아래는 Lab 비교·수정 당시의 이력이다. ‘실제 앱 변경 없음’은 각 Lab 작업 당시의 범위이며, 현재 통합 상태를 뜻하지 않는다. 출처 최소화는 여전히 Lab 시뮬레이션에만 적용한다.

## 무엇을 정리했나

기존 화면은 도시/뒤로가기, Demo, 19+, Options, 검색, 잔액, 온도가 각각 강한 형태를 가져 시선의 우선순위가 불분명했다. 사용자가 A안을 선택한 뒤, 큐레이션 중심이라는 피드백에 따라 검색의 비중을 낮췄다. 최신 수정안은 단어 없는 가로 스펙트럼을 검색 왼쪽에 항상 노출한다. B·C는 이전 비교안으로 유지한다. Lab의 19+는 화면 예시 필터이며 실제 앱의 나이 확인·만료·복귀 처리를 대신하지 않는다.

| 안 | 구성 | 장점 | 실제 적용 시 검토 |
|---|---|---|---|
| A · 큐레이션 아일랜드 **선택·수정안** | 작은 도시/유틸리티 줄 + 글자 없는 가로 스펙트럼·검색 아이콘 | 색과 위치로 직접 탐색하고 검색은 필요할 때 확장 | 실제 지도·이야기·내비게이션과의 통합은 별도 |
| B · 차분한 도시 헤더 | 하나의 흰 헤더 안에 도시 → 검색 → 분위기 | 가장 명료한 읽기 순서 | 상단의 지도 점유 면적이 큼 |
| C · 엄지 중심 커맨드 | 상단은 가볍게, 검색·분위기는 하단 | 한 손 탐색과 넓은 지도 | 기존 하단 탭·이야기·장소 카드를 함께 재배치해야 함 |

세 안은 같은 기능을 다른 위계로 비교한다. 데스크톱에서는 나란히, 1,199px 이하에서는 탭으로 본다. 휴대폰 프레임 안의 주요 터치 영역은 44px, 검색 글자는 16px이다. 현재 Lab은 밝은 테마와 한국어 비교에 한정한다.

A안의 메뉴와 Hot/Warm/Cool 글자는 제거했다. 색상 축에서 세 구간을 탭하거나 드래그하며, 겹쳐 보이던 잎·불꽃 아이콘도 제거했다. 세 구간은 같은 작은 눈금으로 표시하고, 가운데를 선택한 것처럼 보이던 고정 동그라미는 제거했다. ‘전체’는 축 밖의 별도 초기화 버튼이며 초기 상태에는 선택 손잡이가 없다. 드래그 중에는 손잡이만 미리 바뀌고 손을 떼면 지도·추천을 함께 확정한다. 취소·밖으로 놓기·Escape는 미확정 선택을 적용하지 않는다. 버튼의 접근성 이름과 키보드 좌우/Home/End 조작은 유지한다. 검색을 접어도 검색어와 분위기 선택은 유지하며, ‘전체’는 검색어를 지우지 않는다.

2026-09-25 최신: 248px 캡슐 안은 기능 검사를 통과했지만 사용자가 미감과 배치 문제를 지적해 폐기했다. 이제 도시/유틸리티와 필터/검색을 **104px 높이의 단일 2행 헤더**로 묶고 안쪽 버튼 배경을 없앴다. 트랙 6px·선택 손잡이 18px, 레일 좌우 12px 여백으로 정리했다. 검색은 헤더 아래 독립된 행으로 열려 헤더의 폭·위치가 바뀌지 않는다. 지도 위의 ‘지금 끌리는 곳 N곳’ 배지는 없애고 각 카드에 `1 / N · 지역`으로 통합했다. 결과 수의 접근성 안내는 유지한다. 변경 범위는 Lab A와 해당 테스트/기록뿐이며 실제 앱 및 B·C는 유지한다.

A의 서울 추천은 기존 편집 데모 9곳을 재사용한다. 19+ 예시를 제외한 기본값에서는 활기/차분 구간이 각 3곳, 가운데 구간은 1곳이다. 19+ 포함 시 가운데도 3곳이며, 검색 결과를 맞추려고 장소를 임의 보충하지 않는다. 제주 장소는 기존 Lab 가상 예시다. 지도는 직접 그린 SVG이며 실제 좌표가 아닌 배치 위치에서 이동·확대를 시뮬레이션한다. 번호 핀과 하단 가로 추천 목록의 번호가 일치한다. 사진의 기존 출처/이용 조건은 상세에 보존하고 일러스트는 표시한다. 실제 앱의 지도나 추천 데이터는 이번 작업으로 변경하지 않았다.

## A안 출처 최소화 시뮬레이션

- 전체 출처가 실제 화면에 보인 시간 5초가 지나면 `© OpenMapTiles`와 작은 정보 아이콘만 남긴다.
- 화면 밖, 비활성 브라우저 탭, 다른 시트가 덮은 상태, 마우스 hover/키보드 focus 중에는 타이머를 멈춘다.
- 별도 하단 흰 바·예약 여백 없이 지도 위에 배치한다. 글자는 11px, 정보 아이콘은 15px이며 링크와 버튼의 터치 높이는 44px이다.
- 정보 아이콘 또는 지도 옵션 → 지도 출처에서 전체 링크를 연다. `처음 표시 다시 보기`로 초기 5초 표기를 다시 체험할 수 있다.
- 이 Lab은 직접 그린 SVG 지도다. 출처 시트에 실제 데이터 제공자의 지도를 쓰고 있다는 뜻이 아니라 **표기 방식 시뮬레이션**임을 명시했다.

OpenStreetMap의 초기 표시 후 접기 조건과 OpenMapTiles의 가시적 표기를 구분한 안이다. 완전 무표기나 정보 아이콘만 남기는 안으로 해석하지 않는다. 실제 앱의 출처는 아직 변경하지 않았다.

근거: [OSMF interactive-map attribution](https://osmfoundation.org/wiki/Licence/Attribution_Guidelines#Interactive_maps), [OpenMapTiles design license](https://github.com/openmaptiles/openmaptiles/blob/master/LICENSE.md).

## 직접 눌러볼 것

도시 전환/뒤로가기, 검색/0건/초기화, 분위기 필터, 19+ 선택/해제, 지갑 잔액 예시, 지도 지명, 장소 저장, Escape와 포커스 복귀. 모든 상태는 각 안의 메모리에만 남는다. 지도는 비교용 SVG이며 실제 위치 안내가 아니다. 지갑의 60,000 KRW는 고정 예시다.

계정·위치 권한·지갑·결제·인증·체인 API를 호출하지 않는다. 개발 모드 또는 비밀키 없는 로컬 격리 모드에서만 라우트를 연다. 일반 production 환경에서는 `notFound()` 처리한다. `AppProviders` 우회는 정확히 `/labs/header-preview`에만 적용했다.

## 최신 A — 단일 헤더와 카드 내 결과 수 (2026-09-25)

사용자가 지적한 세 문제는 레일 끝 장식과 손잡이의 혼잡, 독립된 캡슐 사이의 어색한 빈 공간, 지도 위에 따로 뜨는 결과 수였다. 이전의 기능 검사 통과를 미적 완성도로 해석하지 않는다.
