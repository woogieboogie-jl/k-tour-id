## 이번 후속 작업에서 더 완료한 것

- 메인 가이드 전용 빌드·서버 접근 프로필을 구현했다. 별도 HttpOnly 쿠키와 정확한 경로/본문/출처 검증을 사용하며 기존 체험 혜택·Preview 쿠키와 섞이지 않는다. **기존 운영 프로필을 이 프로필로 전환한 것은 아니다.**
- 클라이언트는 서버가 알려 준 접근 프로필만 사용한다. 만료 시 같은 operation을 복구하며 새 요청·승인·서명을 자동으로 만들지 않는다.
- Sui의 준비·발급·사용자 제출·대리 실행을 operation 소유권과 연결했다. 서명과 방송 직전에는 실제 커밋된 원장을 다시 확인해야 한다. JSON 파일이나 환경 flag는 이 권한을 만들 수 없다.
- CX→Native→제안→사용자 승인→Sui→Pass→체인 기록의 실제 서버 오케스트레이션을 합성 제공자 경계로 검증했다. 실제 제공자 계약이 없는 부분은 테스트 프로세스에만 주입하며 운영에서는 계속 차단한다.

## 검증과 안전장치

- TypeScript 단위 테스트 **582/582**, JavaScript 테스트 **128/128** 통과. 단위 테스트의 별도 자식 프로세스는 합성 오케스트레이션 **25개**를 추가 검증한다.
- 검증 스위트 **70/70**, TypeScript 검사, 가이드 전용 비활성 빌드 및 기존 운영 프로필 빌드 통과. 배포 결과는 release receipt에서 확인한다.
- 일본어 UI 모바일·데스크톱·320px 브라우저 계약 테스트 **42/42** 통과. 스크린샷을 직접 확인했다. 이 테스트는 외부 요청을 차단한 fixture이며 실연동 증거가 아니다.
- 독립 리뷰에서 중복 저장 전 체인 비용 발생, 취소 후 늦은 응답, provider 상태의 mock 우회, 잘못된 요청 본문, 출처가 다른 signer 복원 경로를 확인하고 방어했다.
- CX, Native, Google, Sui, OmniOne Chain에 이번 UI 검수용 쓰기를 보내지 않았다. 실제 본인 동의나 지갑 서명을 자동화하지 않았다.
- 기존 횟수/가스 원장을 초기화하지 않았으며, 실행 기한은 2026-09-30 23:59:59 KST 그대로다.
- 배포 검증은 같은 소스 SHA의 내부 Preview를 먼저 확인한 후 운영에 반영한다. 사용자에게 Preview에서 본인 인증을 요청하지 않는다.
