추천 순서: 스펙트럼을 움직이고 놓기 → 추천 카드/지도 확인 → 장소 상세와 뒤로가기 → 돋보기에서 검색어 입력 후 분위기 변경 → `전체`로 분위기만 해제 → 도시 전환 → `…`에서 19+/가이드 → 지갑과 지도 복귀.

서버가 종료되면 `/Users/woogieboogie/github/k-tour-id/.codex-worktrees/harvey-sync-20260917/k-tour-id-app`에서 `node scripts/hackathon-local.mjs start 3140`으로 다시 실행한다. 이후 소스를 바꾸었다면 먼저 같은 스크립트의 `build`를 실행한다. 이 worktree에 제공자 `.env`를 복사하지 않는다.

## 바뀐 진입 위치

- 지도 헤더: 뒤로 / 도시 선택 / 공유 지갑 / 지도 설정. 아래 한 줄은 전체 초기화 / 단어 없는 3단계 스펙트럼 / 검색.
- 도시 선택은 기존 서울·부산·제주 진입과 방문 기록을 사용한다.
- 검색은 아이콘으로 펼친다. 일반 검색어와 분위기는 선택 순서에 관계없이 교집합을 유지한다. `전체`는 분위기만 해제한다. 정확한 `hot`, `warm`, `cool` 검색 명령은 Enter로 실행한다.
- 19+·카테고리·지도 시점·위치·언어·도시 가이드는 지도 설정에 모은다. 19+의 기존 상태와 인증창은 계속 유지하며 별도 인증 상태를 만들지 않는다.
- 스토리 읽기에서는 스펙트럼 줄만 접는다. 검색은 첫 줄에서 접근할 수 있고, 검색어를 입력하면 스토리 읽기에서 일반 탐색으로 나간다.
- 추천 순번은 카드 안의 `1 / 3 · 지역`으로 모은다. 스토리 본문·출처·다음/이전·목록·상세 복귀는 기존 컴포넌트를 유지한다.

## 연결 경계

`MapHeaderB`와 `MapHeaderSpectrumB`는 표시·입력만 담당한다. 실제 상태는 `MapEntryB`, 기존 discovery history, `OndoBProvider`가 관리한다. Lab의 SVG 지도·고정 잔액·별도 history는 가져오지 않는다.

스펙트럼 드래그 중에는 선택 미리보기만 바뀐다. 손을 놓으면 추천과 지도 이동을 반영하며, 취소하면 기존 선택을 유지한다. 검색창을 포함한 헤더의 실제 높이를 목록·알림·지도 카메라 여백 계산에 사용한다. 600–899px에서도 분위기를 선택했다고 헤더 형태가 바뀌지 않는다. 극도로 짧은 화면은 기존 목록 대체 화면을 보존한다.

도시·카테고리·19+·잔액 조건 때문에 추천이 0–2개가 될 수 있다. 다른 도시의 장소로 채우거나 실시간 인기도·실제 결제 가능성을 만들어 표시하지 않는다. 지도 출처 정책은 이번 통합에서 변경하지 않는다.

## 검수 범위

1. 분위기 선택 → 지도·카드 → 상세 → 뒤로가기.
2. 검색 후 분위기 / 분위기 후 검색 / 전체 초기화 / 검색 지우기·닫기.
3. 스토리 넘기기·읽기·원문·장소·복귀.
4. 헤더 지갑 → 기존 ID 탭 → 지도 복귀.
5. 지도 설정 → 19+ → 취소·활성·해제·포커스 복귀.
6. 320/390/600/900/1440px, 짧은 가로 화면, 한·영·일, 라이트·다크, 키보드.

검수는 공급자 비밀값을 제외한 `hackathon-local.mjs` 격리 모드에서 진행한다. 따라서 UI 통합 검증이며 CX/Sui/OmniOne 실환경 트랜잭션 E2E 증거가 아니다. OpenDID native holder 보류는 유지한다.
