# 이야기 지도 · 온도 탐색 — 로컬 검수

범위: 기존 앱의 지도 탐색만 개선. 로컬 브랜치 `integration/harvey-preservation-20260924`. 원격 푸시·배포 없음.

## 사용자 흐름

- 도시 지도 → 이야기 배너를 가로로 넘김 → 정착한 이야기의 장소 범위로 지도 이동 → 배너 선택 → 도입/본문 → 장소 상세 → 같은 이야기·읽기 위치·지도 복귀.
- 도시 지도 → 세로 온도 조작 → Hot / Warm / Cool → 해당 지도 핀·장소 카드 → 장소 수 버튼으로 기존 목록 → 장소 상세.
- 온도 선택은 한 필터 단계다. 구간을 여러 번 바꿔도 뒤로가기를 여러 번 요구하지 않는다. 전체 초기화는 온도만 해제하고 현재 도시·분류·일반 검색어를 유지한다.
- 검색창에 Hot / Warm / Cool을 입력하는 기존 진입도 지원한다. 일반 검색어가 있는 상태에서 온도를 고르면 두 조건의 교집합을 보여준다.
- 카드 자동 재생 없음. 초기 표시·복귀·읽기 펼침은 스와이프를 대신 실행하지 않는다. 지도 새 조작은 대기 중인 배너 미리보기를 취소한다. 모션 감소 설정에서는 지도 이동 애니메이션을 생략한다.

## 콘텐츠와 온도 데이터

| 도시 | 이야기 | 연결 장소 |
|---|---|---|
| 서울 | 참기름 따라, 시장으로 | 중부시장 — 개별 기름집으로 오인하지 않도록 시장 위치임을 설명 |
| 서울 | 커피 한 잔, 서울의 시간 | 어니언 안국 · 학림다방 |
| 서울 | 한 그릇으로 만나는 서울 | 고사리 익스프레스 · 옥동식 |
| 제주 | 드라마 속 제주 | 성산일출봉 · 광치기해변 |
| 제주 | K-pop 이야기 | 돈사돈 · 오는정김밥 |

KO/EN/JA 도입·본문·장소별 설명·출처 포함. 기존 검증 장소 ID/좌표/이미지를 재사용하며, 앱이 묶은 대안 코스를 공식 코스나 이동 경로로 표현하지 않는다. 제주 K-pop 연결은 관광공사 콘텐츠의 장소 관계를 사용한다.

서울 온도 데모는 9개 고유 장소, 각 구간 3개다.

- Hot: 어니언 안국 · 금돼지식당 · 런던베이글 도산.
- Warm: 3대삼계장인 · Zest · Bar Cham.
- Cool: 학림다방 · 고사리 익스프레스 · 옥동식.

단일 고정 데모 데이터에서 구간·색을 함께 가져온다. 관심·활기를 표현하는 UI 예시이며 실제 인기/혼잡 측정이 아니다. Cool은 차분하게 즐기는 추천 무드이고 현재 한산함·빈자리·대기 없음의 보장이 아니다. 숫자 점수는 사용자 화면에 표시하지 않는다.

온도 정보 없는 장소를 Cool로 분류하지 않는다. 제주/부산 온도 추천 미제공과 필터 교집합 0건을 구분한다. 분류·After 19·잔액 사용 가능 조건 때문에 결과가 줄어들면 다른 지역 장소로 3개를 임의 보충하지 않는다. 추가된 음식점에 신원/성인/결제 적격성을 새로 부여하지 않는다.

## 레이아웃과 지도 출처

기존 하단 Story/Hot/Cool/List 혼합 바는 이야기 캐러셀과 목록 진입으로 정리하고, 온도는 지도 가장자리의 접이식 조작으로 분리했다. 온도 결과에서는 장소 수 버튼으로 같은 결과의 목록을 연다. 거대한 출처 흰 박스 및 선택 사항인 OpenFreeMap 표기를 지도에서 제거했다.

모바일 지도 설정에는 전체 출처 링크를 추가했다. 다만 OpenMapTiles가 지도 모서리의 가시적 출처를 요구하므로 모바일에도 작은 필수 출처 한 줄은 남긴다. 설정에만 숨겼다고 설명하지 않는다.

- [OpenFreeMap attribution 안내](https://openfreemap.org/)
- [OpenMapTiles 라이선스](https://github.com/openmaptiles/openmaptiles/blob/master/LICENSE.md)

## 개발자 인계 차이

서버 API·Harvey 서비스·SDK·서명·인증·체인 실행·결제 로직 변경 없음. 새 검색/추천 서버 구현은 이번 범위가 아니다.

- 이야기 ID: `sesame`, `seoul-cafes`, `seoul-table`, `screen`, `jeju-kpop`.
- 온도 필터: `hot | warm | cool`. `discoveryDemoTemperatureB`는 데모 출처와 구간을 반환하며 알 수 없는 장소는 `undefined`.
- native history의 온도 변경은 replace, 새로운 이야기/상세 진입은 기존 navigation 경로 유지.
- 제주 음식도 기존 editorial 상세를 사용한다. `discoveryPlaceId`를 통한 시장 상세 우회는 차단한다.
- 실제 신호를 연동하는 후속 작업에서는 데모 데이터와 라이브 신호를 명시적으로 분리해야 한다.

## 반대 관점 리뷰에서 수정한 사항

1. 기존 도시 padding과 이야기 padding의 중복 계산을 제거.
2. 배너 스냅 대기 중 새로운 지도 조작이 발생하면 예약 취소.
3. 지도 비행 중 Back 복원 시 이전 렌더의 검색/분류로 상태가 덮이지 않도록 현재 history만 저장하고 복원 중 저장 차단.
4. 온도 초기화가 변경된 분류를 되돌리지 않도록 수정.
5. 작은 세로 화면에 가로 화면 위치 규칙이 적용되던 문제, 가로 화면 온도 메뉴의 조작 가림, 짧은 화면 결과 카드 하단 잘림 보완.
6. native 터치 스크롤의 `pointercancel`을 손가락을 뗀 것으로 오인해 미리보기를 중간 소모하던 문제 수정. 실제 `touchend` 후 정착한 카드만 반영하고 `touchcancel`은 취소한다. 마우스 휠 검수와 별도로 CDP 터치 입력으로 재현·회귀 검증한다.
